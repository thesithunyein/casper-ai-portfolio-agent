# Quick Start

Full docs live in the root [README.md](./README.md) (keep that as source of truth).

```bash
git clone https://github.com/thesithunyein/casper-ai-portfolio-agent.git
cd casper-ai-portfolio-agent
npm install
cp .env.example .env.local
# set NEXT_PUBLIC_CSPR_CLOUD_API_KEY + OPENAI_API_KEY (+ agent PEM for on-chain)
npm run dev
```
