# Contributing

Thanks for helping improve Casper AI Portfolio Agent.

## Development

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Pull requests

1. Keep the live demo / `main` branch functional at all times (Final Round judges may review anytime).
2. Prefer small, focused PRs with a clear why.
3. Run `npm run lint` and `npm run build` before opening a PR.
4. Do not commit secrets (`.env.local`, private keys, API keys).

## Reporting issues

Open a GitHub issue with:

- What you expected
- What happened
- Steps to reproduce
- Browser / Node version if relevant

## Security

Please do not open public issues for security vulnerabilities. Contact the maintainer privately and allow reasonable time for a fix before disclosure.
